# 开源项目集合

本仓库按「一个项目一个子目录」组织。各子目录相互独立：独立依赖、独立许可证、独立构建方式，互不引用。

## 目录约定

- 每个项目放在独立子目录，目录名用小写英文短横线。
- 每个子目录自带 `README.md` 与许可证文件，不引用根目录资源。
- 构建产物、依赖目录、可执行文件不入库，统一由根目录 `.gitignore` 拦截；个别项目若需例外，在子目录内单独放 `.gitignore`。
- 新增项目时，在上表补一行，并说明上游地址与许可证。

## 分支约定

- `master`：主线，保持可读、可构建。
- 进行中的改动走独立分支，合并前不留临时目录。
